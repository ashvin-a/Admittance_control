System of interest (picture — should have some variables on it. In the text, define all the variables.)

Model the system using some equations that describe how these variables relate to one another. Define 3 things: what's the input, output, and state. 

Input should be something that could be freely chosen. Output matrix. 
Then write the state-space system. xdot = f(xu), y =h(x(t), u(t))

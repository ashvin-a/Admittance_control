=== 5. When CAN a single motor / single angle sensor lose a mode? (hanging equilibrium, g = 9.81) ===
Modes: G v = -mu M0 v. With b_j = [0; M0^-1 e_j], the left eigvec of A gives w^T b_j ∝ v^T e_j = v_j;
with y = theta_j, C x = v_j as well. So joint j's motor (or angle sensor) misses a mode iff that
mode shape has v_j = 0. Solving G e_1 ∝ M0 e_1 gives  m1*l1*l2 = 0  (elbow-only / theta2-only),
and G e_2 ∝ M0 e_2 gives  l1 = 0  (shoulder-only / theta1-only). With l1, l2 > 0 the only
candidate is m1 = 0, where M0 itself is singular (degenerate). Numerical check, sweeping m1:
m1       elbow margin min|v_2|/|v|   shoulder margin min|v_1|/|v|   Kalman rank, elbow-only (numerical)
1        3.83e-01                    3.83e-01                       4/4
0.1      4.88e-02                    4.39e-01                       4/4
0.01     4.99e-03                    4.46e-01                       2/4
0.001    5.00e-04                    4.47e-01                       2/4
0.0001   5.00e-05                    4.47e-01                       2/4
-> the elbow margin shrinks ~ m1/2 but is never zero for a real arm: the 'swing with elbow
   locked' mode is barely excited by elbow torque when the upper link is light. The shoulder
   margin stays O(1). The Kalman rank test already reports rank 2 at m1 = 0.01 although the
   system IS controllable: the Krylov matrix [b Ab A^2b A^3b] is badly conditioned, so use the
   PBH / modal test (or a Gramian) to decide near-degenerate cases, not a numerical rank.
